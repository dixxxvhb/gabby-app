# Bluebird — Gabby's app, v1 (one-shot prototype)

## Decision and why
A single static web app (vanilla HTML/CSS/JS, no build step, no framework) deployed to GitHub Pages at
https://dixxxvhb.github.io/gabby-app/. Free forever. The AI is Google Gemini called straight from the
browser with a free API key Gabby pastes once into Settings (stored in localStorage). Every AI feature has
a scripted fallback so the app is never dead without a key.

Gabby: dancer in Miami, all styles (contemporary, jazz, commercial). First time using AI. Goal = a wow
moment, not perfection. Voice: sweet, caring, warm. Aesthetic: baby blue, grey, cutesy, soft, rounded.

## Files the agent owns
Everything under ~/Code/gabby-app/ except this plan. Target structure:
```
index.html        one page, four tabs + settings sheet
style.css
app.js            router, storage, gemini client, tab modules
data/trivia.json  question bank (>= 200 questions)
data/prompts.js   system prompts + scripted fallback banks
.nojekyll
README.md         one paragraph: what it is, how to get a Gemini key
```

## Hard rules
- No frameworks, no bundler, no npm. Must run by opening index.html and on GitHub Pages as-is.
- No emojis in UI text or design. Use inline SVG icons (simple line icons) and one mascot.
- Never commit an API key. Key lives only in localStorage under `bluebird.geminiKey`.
- Fonts: Google Fonts "Nunito" (body, weights 400/600/800) + "Fraunces" (display, italic allowed). No others.
- Palette tokens on :root. Light only, no dark mode.
  - --sky #DCEFFB (page bg) · --baby #BFE3F5 (cards/accents) · --blue #4A78A8 (primary/text accent)
  - --deep #2C4F78 (headings) · --ink #1F2937 (body text) · --grey #6B7280 (muted) · --mist #F3F6F9 (surfaces)
  - --white #FFFFFF · --blush #FFD6E0 (one warm accent for Theo only, used sparingly)
- Mobile first (390 wide is the primary target; she will use it on her phone). Must also look fine at 1200.
- Everything persists in localStorage under a `bluebird.*` namespace. No backend.
- Gemini: model `gemini-2.5-flash`, REST endpoint
  `https://generativelanguage.googleapis.com/v1beta/models/gemini-2.5-flash:generateContent?key=KEY`.
  Use `systemInstruction` + `contents` (last 20 turns). For the job finder pass `tools:[{google_search:{}}]`
  so results are grounded in real, current listings; render grounding links if returned. If the request
  fails (no key, quota, network) fall back to the scripted bank silently and show a small grey "offline"
  pill, never an error wall.
- Read ~/.claude/design-taste.md before writing any CSS. Avoid: per-item colored dots, glass everywhere,
  eyebrow labels, card-inside-card, gradient text.
- Do not touch anything outside ~/Code/gabby-app. Do not run git push; Fable pushes.

## Intent (build this exactly)
### App shell
- Name: **Bluebird**. Mascot: a tiny round bluebird drawn in inline SVG (two circles + beak + wing), sits in
  the header, blinks on an interval (CSS animation), tilts on hover. Header: mascot + "Bluebird" in
  Fraunces italic + a small settings gear (opens sheet).
- Bottom tab bar, four tabs, icons + labels: **Gigs** · **Theo** · **Quiet Room** · **Daily**.
- First launch: a full-screen welcome (3 swipeable cards, dots, "Let's go" button): "Hi Gabby." /
  what each tab is / paste key or "Skip for now". Sets `bluebird.onboarded`.
- Settings sheet (slides up): Gemini key field with show/hide, link to https://aistudio.google.com/apikey
  with a 3-step how-to, "Test key" button that pings the model and shows a green check, profile fields
  (name, city/zip, styles, height, agency, availability, reel link), "Reset everything" (confirm).

### Tab 1: Gigs (the agent/manager)
- Top: location field prefilled from profile (default "Miami, FL"), editable, any city or zip. Style chips
  (Contemporary, Jazz, Commercial, Hip Hop, Heels, Musical Theatre, Cruise, Theme Park, Music Video,
  Backup Dancer, Teaching) multi-select, prefilled from profile.
- "Find me work" button → Gemini with google_search grounding. Prompt asks for 6-10 current or recurring
  opportunities near LOCATION for STYLES: open calls, auditions, agencies, cruise lines, theme parks,
  studios hiring, festivals. Ask the model for a JSON array; parse leniently (strip code fences). Render
  as cards: title, org, where, when/deadline, why it fits her, a link if grounded. Each card has "Save"
  (heart outline) and "Draft my pitch" (Gemini writes a 4-line email/DM using her profile; copy button).
- Below results: "Always worth checking" section, static curated links built from location:
  Backstage, Casting Networks, Actors Access, Dance Informa auditions, Royal Caribbean Productions,
  Norwegian Creative Studios, Disney Auditions, Universal Auditions, Carnival Entertainment,
  Instagram search for "#[city]dancers" and "#[city]auditions". Open in new tab.
- Manager intake: on first open, if profile is thin, the tab asks 5 quick questions one at a time
  (height, union status, availability, agency, dream gig) as chat bubbles with tap-to-answer chips or
  text; answers save to profile. Manager voice: organized, encouraging, specific.
- Saved gigs list (sub-tabs within Gigs: "Results" / "Saved").
- Scripted fallback (no key): 8 pre-written Miami-flavored opportunity cards from data/prompts.js plus the
  curated links.

### Tab 2: Theo (the companion)
- Persona: **Theo**. Sweet, caring, steady, a little playful, remembers what she tells him, proud of her,
  notices effort, never clingy, never sexual. Talks like a warm boyfriend who is also her biggest fan.
  Short messages (1-3 sentences), asks one question back sometimes, uses her name occasionally.
- Chat UI: bubbles, Theo left in --baby with --blush accent, Gabby right in --blue with white text.
  Typing indicator (three soft dots) before each reply. Long-press a Theo message → "Save to keepsakes".
- Top of tab: a "Today's note from Theo" card that changes daily (seeded by date from a 60-item affirmation
  bank in prompts.js, personalized with her name), with a small heart toggle "keep this".
- Quick chips above input: "I had a hard day" · "Hype me up" · "Tell me something sweet" · "I nailed it today".
- Keepsakes drawer: saved messages and kept notes.
- System prompt includes her profile + last 20 turns + a short memory string Theo can update (the model
  is asked to end replies with `<mem>...</mem>` containing one new fact worth remembering; strip it from
  display, append to `bluebird.theoMemory`, cap 40 lines).
- Scripted fallback: 30 warm replies keyed by chip/keywords.

### Tab 3: Quiet Room (the therapist)
- Not a clinician. Warm, reflective, asks good questions, reflects back, offers one small practical step,
  gently names patterns. No character name, just "Quiet Room". Slower pacing, calmer palette
  (more --mist, less --baby).
- Opens with a mood check-in: 5 faces as simple SVG (rough, low, okay, good, great) + optional one-line
  "what's on your mind". Logged to `bluebird.moods` (date, mood, note). A 14-day mood strip renders at
  the top (small rounded bars, --blue by intensity).
- Chat below, same bubble system. Chips: "I'm anxious about an audition" · "I compared myself again" ·
  "I'm exhausted" · "I want to grow".
- If a message contains crisis words (suicide, kill myself, self-harm, hurt myself, don't want to be here):
  respond with care and show the 988 line (US) card. Hard-coded, does not go through Gemini.
- "Journal" sub-view: dated entries, plain textarea, autosave.
- Scripted fallback: 20 reflective replies.

### Tab 4: Daily (trivia + rewards)
- Question bank data/trivia.json: >= 200 questions, 60% dance (ballet terms, history, choreographers,
  musicals, iconic music videos, competition/commercial world, anatomy, technique) 40% general (pop
  culture, geography, science-lite, words, Miami/Florida). Fields: id, category, q, choices[4], answer
  index, fact (one line). Mix easy/medium/hard. Facts must be true; when unsure, pick a different question.
- Daily Five: 5 questions seeded by date (deterministic), 15s soft timer per question, tap answer,
  instant reveal + fact, points: 100 base + time bonus. Completing today's set = streak day.
- Streak counter with a flame drawn as SVG in --blue (not orange), longest streak, total points.
- Rewards shelf: point thresholds unlock things: 300 "A bonus note from Theo", 800 "New bluebird outfit"
  (mascot gets a tiny bow), 1500 "Golden hour theme" (header bg shifts warm), 2500 "A letter from Theo"
  (a longer written letter), 4000 "Bluebird's secret" (an easter egg screen). Locked = grey card with
  threshold; unlocked = --baby card with "Open".
- Daily Challenge (non-trivia): one per day from a 30-item bank: "Send your reel to one new place",
  "Stretch 10 minutes", "Text someone thank you", with a checkbox worth 150 points.
- "Practice mode": endless random questions, no streak impact.
